Headline answer: is it good enough?

Optuna produced real but modest gains — and its biggest contribution was making the models better calibrated rather than more accurate. Two findings dominate:

  1. Most of the improvement shows up at the default 0.5 threshold. After per-label threshold tuning, baseline and Optuna models converge to nearly the same scores. In other words, Optuna got you threshold-tuned-level performance without needing the threshold hack.
  2. One result got actively worse: on the 5-label Stage 2, per-label threshold tuning dropped macro F1 from 0.56 to 0.46 because the sexually_explicit threshold (0.9730) overfit a tiny validation set. That run's best configuration is now the default 0.5 threshold, not the tuned one.

Net: gains of +0.01 to +0.06 F1. Worth keeping, but the performance ceiling is clearly data-limited, not hyperparameter-limited.

Verdict: best-ever result at 0.5, but threshold tuning backfired.

  • At the default threshold, macro F1 improved 0.53 → 0.56 and sexually_explicit hit 0.67 — the highest score that label has achieved in any experiment.
  • At tuned thresholds, macro F1 collapsed to 0.46. The cause is isolated and clear: the sexually_explicit threshold was tuned to 0.9730, which scored P 1.00 / R 0.33 / F1 0.50 on validation but only P 1.00 / R 0.09 / F1 0.17 on test.
  • Root cause: with just 11 positives in test and roughly 5–6 in validation, the precision-recall curve for that label is built from a handful of points. Picking an extreme cutoff on so few samples is threshold overfitting, not genuine calibration.

Concrete fixes worth applying

  1. Stop tuning thresholds for ultra-rare labels. Gate it on validation positive count — e.g. only tune a label's threshold if it has ≥ 30 validation positives; otherwise keep 0.5. This single guard would have prevented the macro F1 0.56 → 0.46 regression.
  2. Prefer the default-threshold Optuna models. They deliver equal-or-better macro F1 with substantially higher precision (0.59 vs ~0.50), which is a better operating point for moderation than the recall-maximising tuned variants.
  3. Raise the learning rate in any future baseline. Every search moved away from 1e-5 toward 2.5e-5–4.8e-5; the original fixed 1e-5 was underfitting.
  4. If you keep threshold tuning, select thresholds by cross-validated F1 rather than a single validation split, so rare-label cutoffs are less noisy.

Is it good enough?

For the thesis, yes — the search is a legitimate, documented contribution and it improved Stage 2 macro F1 meaningfully at the default threshold (3-label: +0.06; 5-label: +0.03), plus it removed the baseline's suspicious 0.93 threshold dependence.

As an absolute result, no — toxic-class F1 is still ~0.49 and Stage 2 macro F1 ~0.56–0.60. Ten trials over four hyperparameters moved things by hundredths, which is the signature of a data-bound rather than tuning-bound problem. The rare labels (threat F1 0.27–0.29, sexually_explicit unstable between 0.17 and 0.67 depending purely on threshold) remain limited by having 19 and 11 test positives. More annotated data for those categories would move the numbers far more than any further hyperparameter search.
